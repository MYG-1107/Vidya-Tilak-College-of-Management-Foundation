# University / institution logos

Place official logo images in this folder using these exact filenames so the website can display them:

- `mangalayatan.jpeg` — Mangalayatan University
- `dypatel.jpeg` — Dr. D. Y. Patil Vidyapeeth
- `mtsou.jpeg` — Mata Tripura Sundari Open University
- `ignou.jpeg` — Indira Gandhi National Open University (used in research examples)
- `iima.jpeg` — Indian Institute of Management Ahmedabad (used in research examples)
- `bits-pilani.jpeg` — BITS Pilani (used in UG examples)
- `christ-university.jpeg` — CHRIST University (used in programme examples)
- `harvard.jpeg` — Harvard University / Harvard College (used in international examples)
- `oxford.jpeg` — University of Oxford (used in international examples)

Recommended: use the institution's official logo with permission, preferably a square/transparent PNG or high-quality JPEG. The pages contain text fallbacks, so the site still looks correct when a logo has not yet been added.
