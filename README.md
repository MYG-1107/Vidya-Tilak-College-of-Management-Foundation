# Vidya Tilak College of Management Foundation — Refined Website

This is a static HTML/CSS/JS rebuild focused on a more editorial, institutional visual language, responsive navigation, the official repository logo (`/logo.jpeg`), and page-level SEO metadata.

## Important
The repository already contains the official `logo.jpeg` at its root. The HTML in this package references that file as `logo.jpeg`; keep the image in the repository root when copying these files.

## Local preview
Run `python -m http.server 8000` from the project folder and open `http://localhost:8000/`.

## SEO included
- Unique page titles and descriptions
- Canonical URLs
- Open Graph metadata
- Organization JSON-LD
- `robots.txt`
- `sitemap.xml`
- Semantic headings and descriptive internal links
- Dedicated pages for research, publications, conferences, events, gallery, FAQs, privacy, terms and careers

## Content policy
Claims that require official evidence (fees, accreditation, placement outcomes, indexing, rankings, awards, vacancies, etc.) are deliberately not invented. Add verified details when supplied by the organisation.
